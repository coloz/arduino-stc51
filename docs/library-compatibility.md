# 库兼容说明

随平台维护的库声明为 `architectures=mcs251`，不再提供其他 CPU 架构配置。

| 库 | 支持范围 |
| --- | --- |
| Wire | 7 位 I²C 主机；按型号选择硬件控制器或软件回退；默认收发缓冲各 32 字节 |
| SPI | 主机、模式 0～3、MSB/LSB；按型号选择硬件控制器或软件回退；应用负责片选 |
| SoftwareSerial | 轮询收发，不保证阻塞刷屏期间接收连续数据 |
| LiquidCrystal | 并行字符 LCD |
| Stepper | 基本步进序列；调用可阻塞 |
| SD | FAT16/FAT32 根目录 8.3 文件读取、创建、追加、覆盖、flush 和删除；单文件，不支持目录、exFAT 或断电原子写入 |

默认库 API 同时保留 plain C 函数表入口和显式 C++ 类入口。外设布局、时钟、引脚冲突、事务及错误返回值见[实际开发说明](arduino-practical-api.md)。

## 内存与应用组合

库出现在安装包中，不代表任意 API 组合都能装入每个型号。编译后核对 Flash、RAM、堆和栈占用；小容量型号优先采用容量合适的单外设或控制应用，见[应用范围](application-scope.md)。

大块帧缓冲、ArduinoJson 内存池和 String 会竞争固定堆。优先复用缓冲并检查分配结果；普通 new 失败进入 panic，不抛异常。U8g2/U8x8 等第三方库需按具体版本、屏幕模式、帧缓冲大小和芯片容量构建，并验证实际设备。

## SD 与原生 C 接口

SD 的 C 后端与 C++ File 共用实现。检查打开、读写和 flush 的结果；卡片故障、掉电恢复与文件一致性由应用按实际介质验证。主机模拟块设备和编译检查不能代替 SD 卡实测。

不得直接链接 Keil C251 预编译库，需从兼容源代码重建。库若通过函数指针与原生 C 交互，应使用标量或显式结果指针接口；不兼容的聚合对象按值跨界调用会被 ABI 检查拒绝。完整约定见[C++ 运行时说明](cpp-runtime-contract.md)。
