# Arduino 常用库兼容性复测（2026-09-16）

本轮 20 组用例有 **17 组通过编译、链接和离线 HEX 校验，3 组仍失败**。
本次点名的 U8g2、DHT、RTClib、TFT_eSPI、NeoPixel 五组在最终源码安装副本上全部通过。
NeoPixel 使用明确标记的 **1.15.5-stc.1 平台移植版**；其余通过项使用固定版本的原始第三方库。

测试目标是 `arduino-stc51:mcs251:stc32g144k246:clock=12m`，宿主为 Windows x64，
Arduino CLI 1.5.1，使用锁定的原生 Clang → LLVM-CBE → SDCC 工具链。
所有结果限于所列用例，**未进行烧录、实板运行或外设波形验证**，也不能据此推广到全部板型、全部库功能。

本文保留清理前的验证结论、资源占用和适用范围；测试文件及临时构建产物已按要求删除。

## 本轮修复

### U8g2：长命令行和依赖文件冲突

Windows 驱动将函数归档参数写入 UTF-8 JSON 文件，辅助进程只接收文件路径。
解析后仍逐项验证参数、元数据、输入文件和链接闭包；SDAR 使用归档目录内的短文件名。
最终 U8g2 构建包含 132 个成员，对应原始参数字符串 **40,485 字符**，已超过 Windows
32,767 字符的进程命令行限制，而本轮正常通过。

C 依赖扫描在独立临时目录生成 `.d`，复制到目标旁的临时文件、关闭后原子发布。
重复扫描替换已存在依赖文件、失败时保留旧文件和临时文件清理均有回归检查。
最终五组复测使用三组并发、每组 `--jobs 4`；U8g2 不再依赖缩短路径或单线程。

### DHT：warning 84

Clang 的清理分支让多个返回路径共用一个析构调用和 selector switch，SDCC 无法关联
selector 与已经赋值的返回槽。适配器仅在每条入边都紧邻常量 selector 赋值、selector 无其他使用或逃逸时，
复制清理调用并直接跳到已知目标，保持析构顺序与次数。
此次识别并转换 DHT 中的三条清理入边，没有给返回值补造默认值。

### RTClib：warning 196

对已经证明只读取一个字节的辅助函数，以及只来自静态 const 字节数组、不逃逸且只赋值一次的局部别名链，
恢复 `const` 参数、指针声明和字节地址转换。此次覆盖星期和月份名称的两条读取链。
写入、未知调用、重新赋值、可变存储等形式保留原状，继续受告警审计约束。

这两项没有全局关闭 warning 84 或 warning 196。已有的、经审计确认安全的 CBE 算术辅助函数 `r`
告警仍可能出现在日志中；本轮解决的是原先阻止构建的新增形式。

### TFT_eSPI：C++ 诊断与基础接口

Windows 和 POSIX 驱动对 `non-c-typedef-for-linkage`、`implicit-const-int-float-conversion`
保留警告，不再将它们提升为错误；其他默认错误和 SDCC 后端审计继续保留。
补齐 `fmin/fmax/fminf/fmaxf` 及 `itoa/utoa/ltoa/ultoa`。
数值实现覆盖 NaN、正负零、带符号整数最小值及 2～36 进制。
通用 SPI 用例通过，不代表 ESP 专用 DMA、并口或全部 TFT_eSPI 扩展功能已实现。

额外的数值 API 用例还发现 CBE 位转换联合体含未使用的 `double Double` 字段。
在确认无字段访问且完整联合体形状匹配时移除该成员，保留 `uint64_t` 成员所决定的大小及对齐，
避免 SDCC warning 93；真实成员访问或不同布局不会被此规则改写。

### NeoPixel：独立 STC 输出实现

平台随附基于上游 1.15.5 的 `1.15.5-stc.1` 移植，保留来源摘要和 LGPL 许可。
测试器同时校验实际选中版本与平台库目录，库管理器下载副本没有修改。

当前范围为 STC32G144K246 的 12/48 MHz、P0～P7 有效 GPIO、800 kHz、RGB/RGBW。
输出时序由 SDCC 汇编直接操作端口位，保存中断使能状态；像素缓冲额外分配一个预取字节并检查长度溢出。
无效引脚、400 kHz 的 `begin()` 返回 false，其他芯片有明确编译诊断。

**该后端仍属实验性实现。** 12 MHz 与 48 MHz 均通过编译、链接、HEX 校验，
指令模型覆盖每个端口位、全部字节值、256/257 字节计数边界及预取范围；
缓存、跳转周期和实际 GPIO 波形尚未用实板确认。
时序计算来源、手册周期注释差异和使用说明见 [NeoPixel 移植说明](../libraries/Adafruit_NeoPixel/README-STC.md)。
