# 按应用选择型号与功能

支持范围以型号、时钟、应用功能和工具链版本的组合为单位。小容量芯片适合简单控制，不要求它容纳大型多库程序；容量较大也不代表任意库组合都已适配。

| 应用 | 选型和验证重点 |
| --- | --- |
| 小型控制 | GPIO、定时调度、串口状态输出、启动及重复执行 |
| 单个外设 | 所选型号、时钟、引脚及 UART、I²C、SPI、ADC、PWM 或中断能力 |
| 多对象或多库组合 | 对象生命周期、资源占用、缓冲区及堆栈余量 |
| 文件系统和持久化 | 文件读写、介质错误恢复，以及产品需要的掉电恢复 |

16 KB 的 AI8051U-34K16 应优先使用容量合适的控制程序或单外设应用。软件能通过编译或模拟执行，仍需在产品板验证实际波特率、时间精度、引脚负载和外部设备。

## 处理容量不足

1. 按编译和 HEX 校验结果检查芯片真实的 Flash/RAM 限制；超容量程序不能烧录。
2. 缩小应用功能、减少缓冲或选择容量更大的型号，再重新编译和运行。
3. 大型压力程序超限不说明所有小型应用不可用；必须以实际要交付的应用验证。
4. 容量合适时的编译错误、错误输出、越界访问和运行失败需要单独定位。

硬件操作步骤见[硬件验证说明](hardware-validation.md)，库的功能限制见[库兼容说明](library-compatibility.md)。
