# MCS251 编译与实板验证

仅测试 `tools/variants/devices.json` 中的 10 个保留型号。每个结果应绑定源码、工具锁、FQBN、HEX 哈希、芯片及封装、时钟和接线。

先检查生成元数据，再编译 plain C/C++ 与使用的库；验证 HEX 地址、容量、HOME、堆栈及链接审计。优先运行匹配型号的 QEMU，验证构造函数、内存、串口协议和可模拟 GPIO/计时行为。QEMU 串口 socket 不按物理波特率限速，回显测试需控制发送节奏。

实板使用匹配的 stc-cli 执行 validate/flash，再测时钟、串口、GPIO、中断、总线错误处理及外设。屏幕和 LED 由实际观察确认；波形速率需测量。构建成功、QEMU 成功和实板成功分别记录，不互相替代。不得把旧报告中的已移除型号重新纳入平台矩阵。
